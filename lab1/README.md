# Sculptor (lab1)

Простая симуляция: шариком управляешь с клавиатуры внутри прямоугольной рамки, он расширяется по нажатию клавиши.
Рисуется только **пересечение** шарика и рамки — всё, что выходит за рамку, отсекается.

## Управление

| Клавиша     | Действие                  |
|-------------|---------------------------|
| `WASD` / стрелки | двигать шарик        |
| `Space`     | расширять шарик (зажать)  |
| `Backspace` | сжимать шарик (зажать)    |
| `Esc`       | выход                     |

В заголовке окна показываются радиус и «давление» — доля площади шарика, срезанная стенками (0..1).

## Сборка

Нужны компилятор с C++20 (`std::format` — GCC 13+ / Clang 17+), CMake ≥ 3.16 и SFML 3.

```sh
# Arch
sudo pacman -S sfml cmake

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/sculptor
```

Если системного SFML 3 нет, CMake сам скачает его с GitHub (понадобятся dev-пакеты X11/OpenGL/FreeType/udev).

## Структура

```
include/
  coord_traits.hpp  — категории координат и vec_t<T>
  cell.hpp          — прямоугольная рамка
  bubble.hpp        — шарик (центр, радиус, цвет)
  physics.hpp       — движение, упор в стены, отсечение круга рамкой
src/
  main.cpp          — окно, ввод, отрисовка
scripts/
  commit_steps.sh   — поэтапные коммиты (см. ниже)
```

## Как работает пересечение

Круг аппроксимируется 128-угольником, затем выпуклый многоугольник последовательно
отсекается четырьмя полуплоскостями рамки (алгоритм Сазерленда — Ходжмена).
Результат кладётся в `sf::ConvexShape` и рисуется как есть.
